# 🎵 Biblioteca Musical

## 📋 Descrição
Este projeto apresenta uma página de listagem de músicas, desenvolvida com HTML e CSS. A página permite visualizar músicas, artistas, álbuns, gêneros e opções de ações.

## 🎯 Objetivo
Praticar os conceitos de HTML e CSS, organizando informações em uma página web.

## 💻 Arquivos do projeto

- **listagem_musicas.html:** contém a estrutura da página, os filtros e a tabela de músicas.
- **styles.css:** contém a parte visual da página, como cores, botões, tabelas, espaçamentos e organização dos elementos.

## 🎼 Funcionalidades
- Exibição de músicas cadastradas.
- Filtro por título, álbum ou artista.
- Seleção de artista e gênero.
- Botões para editar e excluir.
- Link para assistir às músicas no YouTube.

## 🛠️ Tecnologias utilizadas
- HTML5
- CSS3

## 📁 Organização dos arquivos

```text
Biblioteca-Musical/
│
├── listagem_musicas.html
├── styles.css
└── README.md
```

## ▶️ Como executar
1. Baixe os arquivos do projeto.
2. Coloque os dois arquivos na mesma pasta.
3. Abra o arquivo `listagem_musicas.html` no navegador.

## 📚 Conclusão
A atividade permitiu praticar a criação de páginas HTML e a estilização com CSS, desenvolvendo uma interface simples para uma biblioteca musical.
